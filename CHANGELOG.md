# Changelog

## 0.3.0

- Registry installation guides for npm, pnpm, Yarn and Bun, with matching copyable commands and AI prompts in the playground.
- Tag-based npm Trusted Publishing with a separate checked-archive job, provenance, retry/collision protection and a manual dry run.
- Documented first-publication setup and release procedure; no long-lived npm publishing token.
- Reversible Button, Floating and Tab motion, full-screen mobile overlays and a narrower desktop Tab face with its existing pointer target.
- Localized recovery for blocked embedding, exact-site diagnostics and a direct link to the Website setting.
- React prop removal restores defaults, including switching between local and Live previews.

## 0.2.1

- React-first playground with separate React, Next.js, JavaScript and Web Component setup guides.
- Copyable install commands, JSX/layout examples, registration/HTML files and framework-specific AI prompts.
- Shared package-root imports in JavaScript examples and generated code.
- Real React component previews with automatic cleanup and state preserved between React / Next.js guide selection.
- Packed-package Next.js consumer QA for metadata, hydration, navigation and refresh.

## 0.2.0

- Four separate reservation components with their own presentation modules and JS entry points.
- React / Next.js components and four fixed Web Components; no `mode` setting in the new API.
- Restaurant configuration accepts either a public slug or a MenüQR menu link.
- Playground restaurant field, explicit live-preview opt-in and generated component-specific code / AI prompts.
- Preview form matches the WordPress guest interface, including dates, party size, contacts, languages and the linked MenüQR footer.
- Shared module registry across package entry points; 0.1.x APIs remain available for compatibility.

## 0.1.0

Initial public MVP.

- Typed JavaScript API with button, floating, edge tab and inline layouts.
- Explicitly registered Web Component, nine UI languages and configurable accent/placement.
- SSR-safe ESM/CommonJS builds and TypeScript declarations; no runtime dependencies.
- Isolated styling, native dialog focus/dismissal and iframe origin/source validation.
- Local playground, cross-origin preview fixture and configured AI integration prompts.
- Unit tests and browser integration tests including React Strict Mode and Vue lifecycle.
- GitHub release archive distribution; npm registry publication is deferred.
